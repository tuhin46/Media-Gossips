# Media Gossips

AngularJS entertainment news website with a custom admin panel. This integration branch moves shared content, the breaking-news ticker, and uploaded images to Google Drive through Apps Script and a protected Vercel API. The website layout remains intact; bookmarks stay local to each visitor.

Deployment and migration must be completed before these changes become live. Follow [the setup guide](storage/SETUP.md), using **smtuhin46@gmail.com** for Apps Script and the live-content folder.

Run local checks with `node --test tests/*.test.js` from this repository root.
